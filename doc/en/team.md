# Guide for professionals and families

This guide is intended for occupational therapists, families,
teachers and other professionals who want to use Calculia as a
support tool to practise math and reasoning.

---

## Who is Calculia for?

Calculia is primarily designed for:

- **People with intellectual disability** who want to practise
  calculation and reasoning skills autonomously.
- **Families** looking for resources to work on math at home.
- **Teachers and therapists** who need complementary tools for
  direct intervention.

The application **does not replace** professional intervention, but
can serve as:

- Reinforcement between sessions.
- Autonomous practice at home or in class.
- Progress tracking of the learner.

---

## How to use Calculia in support sessions

### Initial assessment

Before using the application, observe the learner with these
questions:

1. What level of autonomy do they have when reading and writing
   numbers?
2. What skills do they want to work on? (calculation, money,
   reasoning, patterns…)
3. Which activities are attractive or motivating to them?
4. Do they need support to use technological devices?

### Activity selection (examples)

#### For users starting out

| Activity | Skill worked |
|----------|--------------|
| **Numbers** | Number recognition, counting. |
| **Quantities** | Comparing, "more / less / equal". |
| **Mental math** | Simple additions and subtractions. |
| **Temperature** | Reading a thermometer. |

#### For intermediate users

| Activity | Skill worked |
|----------|--------------|
| **Math tables** | Multiplication facts. |
| **Fractions and measures** | Fractions, units of measure. |
| **Money** | Counting coins and banknotes. |
| **Stories** | Extracting data from a short problem. |

#### For advanced users

| Activity | Skill worked |
|----------|--------------|
| **Wallet** | Change, budgeting. |
| **Clock** | Reading the time and durations. |
| **Riddles** | Verbal reasoning. |
| **Patterns** | Detecting rules in a sequence. |
| **Puzzle** | Spatial reasoning. |
| **Roman numerals** | Number-system translation. |

### Adaptations

#### Difficulty level

Each activity has **3 levels** (Easy → Medium → Hard). To choose:

- **Level 1 (Easy)**: new users or those with significant support.
- **Level 2 (Medium)**: users with moderate experience.
- **Level 3 (Hard)**: autonomous users looking for challenge.

#### Reductions

If level 1 is still too difficult, you can:

- Reduce the number of elements (e.g. fewer options in "Odd one out").
- Provide physical support to guide the action.
- Use the activity as demonstration before requesting autonomy.

## Progress tracking

### Stars

Each activity saves **stars** when completed (a level finished):

- ⭐ = 1 star
- ⭐⭐ = 2 stars
- ⭐⭐⭐ = 3 stars (all levels)

To view progress:

1. Access settings by appending `/settings` to the URL (see
   [`quick-guide.md`](quick-guide.md) §9).
2. Check **My progress** for a summary.

### Privacy

Progress is stored **only in the browser's `localStorage`**.
It never leaves the device. See the legal page for the
full privacy statement.
