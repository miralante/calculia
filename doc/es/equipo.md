# Guía para profesionales y familias

Esta guía está pensada para terapeutas ocupacionales, familias,
docentes y otros profesionales que quieran usar Calculia como
herramienta de apoyo para practicar cálculo y razonamiento.

---

## ¿Para quién es Calculia?

Calculia está diseñada principalmente para:

- **Personas con discapacidad intelectual** que quieran practicar
  habilidades de cálculo y razonamiento de forma autónoma.
- **Familias** que buscan recursos para trabajar las matemáticas en
  casa.
- **Docentes y terapeutas** que necesitan herramientas
  complementarias para la intervención directa.

La aplicación **no sustituye** la intervención profesional, pero
puede servir como:

- Refuerzo entre sesiones.
- Práctica autónoma en casa o en clase.
- Seguimiento del progreso de la persona.

---

## Cómo usar Calculia en las sesiones de apoyo

### Valoración inicial

Antes de usar la aplicación, observa a la persona con estas
preguntas:

1. ¿Qué nivel de autonomía tiene al leer y escribir números?
2. ¿Qué habilidades quiere trabajar? (cálculo, dinero,
   razonamiento, patrones…)
3. ¿Qué actividades le resultan atractivas o motivadoras?
4. ¿Necesita apoyo para manejar dispositivos tecnológicos?

### Selección de actividades (ejemplos)

#### Para personas que empiezan

| Actividad | Habilidad trabajada |
|-----------|---------------------|
| **Números** | Reconocimiento numérico, conteo. |
| **Cantidades** | Comparar, "más / menos / igual". |
| **Cálculo mental** | Sumas y restas sencillas. |
| **Temperatura** | Lectura del termómetro. |

#### Para personas con nivel intermedio

| Actividad | Habilidad trabajada |
|-----------|---------------------|
| **Tablas de multiplicar** | Tablas de multiplicar. |
| **Fracciones y medidas** | Fracciones, unidades de medida. |
| **Dinero** | Contar monedas y billetes. |
| **Cuentos** | Extraer datos de un problema breve. |

#### Para personas con nivel avanzado

| Actividad | Habilidad trabajada |
|-----------|---------------------|
| **Cartera** | Vueltas, presupuesto. |
| **Reloj** | Lectura de la hora y duraciones. |
| **Acertijos** | Razonamiento verbal. |
| **Patrones** | Detectar la regla de una secuencia. |
| **Puzzle** | Razonamiento espacial. |
| **Números romanos** | Traducción entre sistemas de numeración. |

### Adaptaciones

#### Nivel de dificultad

Cada actividad tiene **3 niveles** (Fácil → Medio → Difícil). Para
elegir:

- **Nivel 1 (Fácil)**: personas nuevas o con apoyo significativo.
- **Nivel 2 (Medio)**: personas con experiencia moderada.
- **Nivel 3 (Difícil)**: personas autónomas que buscan reto.

#### Reducciones

Si el nivel 1 sigue siendo demasiado difícil, puedes:

- Reducir el número de elementos (p. ej. menos opciones en
  "Qué sobra").
- Ofrecer apoyo físico para guiar la acción.
- Usar la actividad como demostración antes de pedir autonomía.

## Seguimiento del progreso

### Estrellas

Cada actividad guarda **estrellas** al completarse (un nivel
terminado):

- ⭐ = 1 estrella
- ⭐⭐ = 2 estrellas
- ⭐⭐⭐ = 3 estrellas (todos los niveles)

Para ver el progreso:

1. Entra en ajustes añadiendo `/settings` a la URL (ver
   [`guia-rapida.md`](guia-rapida.md) §9).
2. Consulta **Mi progreso** para ver el resumen.

### Privacidad

El progreso se guarda **solo en el `localStorage` del navegador**.
No sale del dispositivo. Consulta la página legal para la
información completa de privacidad.
